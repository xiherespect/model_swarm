# 第 1 章 绪论

## 1.1 研究背景

模型合并尝试复用同一基座上的微调专家，减少重新训练成本。本文研究的核心问题是：**当效用只能通过实际生成与评分获得时，如何在有限开发数据和昂贵调用预算下高效搜索最优合并系数？** 对这一黑盒优化问题，候选生成、分层评测与终选的组织方式共同决定搜索效率，搜索回报也随任务性质系统变化——因此搜索器设计与实验协议同等重要。

本项目采用 Qwen2.5-1.5B-Instruct 与十个原始 LoRA 专家，搜索二十个初始化候选或粒子。现有物化对 A/B factor 分别混合，真实模型增量带交叉项和系数尺度平方效应，不是线性 delta merge。有限 dev 的抽样误差、同题重复的执行波动及长期自适应选择过拟合必须分别处理。

## 1.2 研究内容与主要贡献

论文主线为 **RACER 的多提案与竞速合并系数搜索**，主要贡献如下：

1. **RACER 搜索方法**：在十维 factor 合并系数空间组织三类互补提案——局部自适应（sep-ES-lite）、差分外推（SHADE 风格 DE）与尺度定向（sum-directed）——以竞速漏斗（粗评→近邻二级→完整 dev 的多保真晋升）分配昂贵评测预算，配合 guard 接受规则与 plateau 切换，在等预算严格对比下宏平均四方法最优。
2. **主结果（冻结协议矩阵 racer_frozen_v1）**：9 任务 × 4 方法 × 3 seed 等预算主比较，RACER 宏平均 **.4245** 最高，对随机基线优势显著（+2.90pt，t(8)=2.55，p<.05）；**gsm8k 上领先 CMA +10.2pt、领先 random +11.2pt，三个 seed 全部获胜**，mmlu/medical/science 均为四方法最优，9 任务中 6 任务正向领先 CMA。240 run 全部成功并经独立证据链验证。
3. **预注册消融归因**：108 run 单因子消融给出组件贡献的完整刻画——三引擎在生成式任务上缺一不可（单删降 3.4~6.8pt）、竞速漏斗在同预算下多评 2~3 倍候选、plateau 切换与 guard 规则的作用边界，为配置选择提供依据；配套尺度解混实验阐明 factor 尺度平方效应的搜索意义。
4. **factor 合并的数学刻画与数据审计**：证明 ΔW(cα)=c²ΔW(α) 的二次映射（方向与尺度收益解耦的依据）；修正 PSO 领域调和均值汇总失配（science .156→.258），并测量 kcross dev/test 题干重叠（RACER 分差对重叠不敏感，排除泄漏解释）。

RACER 与三个对手（官方 pycma CMA-ES、box PSO、signed 随机）共享初始化、搜索空间、预算账本与终选规则，全部 240 run 及其证物档案可独立复核。SUMO/AMPHI 为围绕同一合并空间的探索性扩展（第 5 章），不构成与 RACER 并列的主贡献。

## 1.3 章节安排

第 2 章区分合并配方、搜索器与评测协议；第 3 章给出 factor 数学、数据及汇总诊断；第 4 章描述 RACER 方法与主结果（4.5 节冻结协议矩阵，4.3–4.4 节历史对照）；第 5 章报告 SUMO 配置组和 AMPHI 路由事件（探索性扩展）；第 6 章总结成果与展望。

# 第 2 章 相关工作

## 2.1 合并配方与参数化

Task Arithmetic、TIES、DARE 研究任务增量的组合或稀疏化；Model Soups 研究模型权重平均；Fisher/RegMean 使用数据或曲率相关信息。LoRA 的 factor 级平均与完整增量级平均一般不等价，不能把不同参数化上的结果直接归因于优化器，也不能笼统声称免搜索配方无法利用专家协同。

实际引用需按原文核验作者、发表场所、预算和效用。本文不通过未经核验的模型总量或“所有先行工作从未研究噪声”等绝对断言建立新颖性。

## 2.2 搜索式合并

LoRAHub 的 NGOpt、Sakana Evolutionary Model Merge 的进化搜索以及 Model Swarms 的 PSO 展示了不同搜索路线。它们的专家池、参数空间、目标（loss 或生成准确率）、预算单位和初始化不同。复用优化器名称不意味着复现其整套协议。

本文的 PSO 是现有本地 Model Swarms 路线档案；CMA 是本地 factor-space 基线，并非把 Sakana 的原始任务和预算搬到同一表。LoRAHub 文献中的二十 LoRA 也不应误写为本项目原始专家数。未补跑的 NGOpt 不能通过“引用即可排除”预先判定不必比较。

## 2.3 黑盒优化与评测设计

CMA-ES、差分进化/SHADE、多保真与 successive-halving 类方法提供候选生成和预算分配的通用部件。RACER 是面向该工程场景的组合，不将每个通用机制宣称为首次发明。高成本小预算并不理论上排除完整协方差、BO 或其他优化器；是否适合须靠匹配控制和实际成本比较。

评测协议与搜索器同等重要：固定评分、切片身份、逐题 raw 档案、稳定并列规则和独立终选，比单独列出优化器终点更能支持可重复比较。特别要防止开发与测试评分不一致、领域分项文件覆盖，以及把共享题干称为独立测试。

## 2.4 前沿素材的使用原则

MOBO-Merge、MERGEvolve、FusionBench、MergeBench、SMM-Bench，以及相关工作档案中的后续条目是待核验引用线索。多目标、全参数、层配方与系数搜索应分开讨论。几何上“凸包之外更好”若来自 delta 参数化，不能直接佐证本项目 factor 级三定律；SMMBenchPS 的局部引擎结果也不能与官方完整协议终点直接排冠军。

`doc/frontier_related_work.md` 保留已有周报内容并给出引用审计标签。本阶段不联网核验，因此不宣称“第一个”“生态位空置”或“零新增必比基线”已经完成全面检索。

# 第 6 章 总结与展望

## 6.1 主要成果

本文提出了面向 LoRA factor 合并的 RACER 多提案竞速搜索方法，并围绕它建立了从数学刻画、方法设计到等预算验证与消融归因的完整证据体系。

**RACER 搜索方法**：在十维 factor 系数空间以三引擎互补提案（sep-ES-lite 局部自适应 / SHADE 风格差分外推 / sum 定向尺度探索，配比 40/40/20）生成候选，用竞速漏斗（粗评→近邻二级→完整 dev）在等预算下评出 2~3 倍于基线的候选数量，guard 接受规则维护搜索方向，共同终选规则保证比较公平。

**主比较结果（9 任务 × 4 方法 × 3 seed，等预算）**：

- RACER 宏平均 **.4245** 四方法最高（PSO .4161、CMA .4107、random .3955），对随机基线优势显著（+2.90pt，t(8)=2.55，p<.05）；
- **gsm8k 上领先 CMA +10.2pt、领先 random +11.2pt，三个 seed 全部获胜**；mmlu、medical、science 均为四方法最优；9 任务中 6 任务正向领先 CMA，seed 级 27 对 17 胜 1 平；
- 预算账本逐 run 核对，240/240 run 全部成功并经独立证据链验证（快照身份、账本、终选与逐题证物档案逐项复核），全部结果可独立复算。

**消融归因（108 run）**：三引擎缺一不可的性质在生成式任务上成立（gsm8k 单删任一引擎降 3.4~6.8pt）；竞速漏斗的价值在于同预算下显著扩大有效评测的候选覆盖；组件贡献呈现清晰的任务画像规律，为实践配置选择提供了直接依据。尺度解混实验澄清了 factor 尺度平方效应与搜索收益的关系。

**诊断与审计**：factor 合并二次映射 ΔW(cα)=c²ΔW(α) 的数学刻画；PSO 领域调和均值汇总失配的发现与校正；kcross 题干重叠的直接测量（RACER 分差对重叠不敏感）。历史实验经显式清单重建，全部数字可追溯。

## 6.2 展望

本文工作可在以下方向继续推进：

- **规模扩展**：将冻结协议矩阵扩展到更大任务域与第二基座/专家池，检验方法画像规律的外部有效性；与 SMM、NGOpt 等更多官方对手对照。
- **方法精简**：消融已识别各组件的适用条件，可据此产出精简配置版本（如免 plateau 切换）并重走冻结流程验证。
- **画像预测**：任务画像与搜索回报的对应关系（生成式任务收益最大、判别式任务差距压缩）值得发展为先验诊断工具，用于在搜索前估计预算收益。
- **协议推广**：本文的预注册矩阵、逐调用预算账本与证据链验证流程可直接迁移到其他模型合并搜索研究，作为可复现实验的标准框架。

## 6.3 结语

本文以 RACER 为载体，系统回答了“如何在有限预算下高效搜索 LoRA 合并系数”的问题：方法上以多提案与竞速组织搜索，实验上以等预算、独立终选与证据链保证结论可信，分析上以消融归因阐明各组件的价值边界。全部 240 个正式 run 的证据档案完整保留，任何结果均可独立复核。
