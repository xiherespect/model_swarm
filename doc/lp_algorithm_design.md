# LP-Merge：LLM 专家合并的低维自适应搜索算法

**设计文档 v0.1** · 2026-09-04 · 状态：设计定稿，待实现

---

## 0. 一句话主张

> 我们将 LLM 专家合并重构为**专家张成空间中的低维黑盒优化问题**（≤10 维），给出**仿射包/张成空间的二层逃逸分析**，据此提出领域结构感知的搜索算法 **LP-Merge**（稀疏选择先验 + 协同矩阵引导 + 定向外插），在统一评测框架下以更少预算超过群体/GA 方法。

---

## 1. 背景与问题定义

### 1.1 任务设定（Model Swarms setting）

- **输入**：n 个同源 LoRA 专家 {e_1..e_n}（同一基座微调），效用函数 f（200 条 dev 样本上的任务准确率）
- **输出**：合并后的最优专家 g
- **操作集**：模型权重的线性算术（合并即 Σ αᵢ eᵢ）
- **约束**：无梯度、无微调、评估昂贵（每次 f 评估 = 全量推理约 1–3 分钟）

### 1.2 我们的复现资产（Qwen2.5-1.5B 基座）

| 实验 | dev 轨迹 | 关键观察 |
|---|---|---|
| nlgraph（12 轮，早停边缘手动停） | 0.365 → 0.48 | iter 3 后 9 轮无提升；粒子 restart 无效 → **平台期待解释（§2.3）** |
| hellaswag（12 轮，早停） | dev 0.625 → **0.65**，test 0.577 → **0.562** | **dev-test 漂移**：200 条 dev 的选择噪声使 dev 提升不迁移到 test → 多保真+复评机制的直接动机 |

基础设施：修好的 evaluate.py（LoRA 加载 + padding 修复）、4×12GB GPU、run_search.sh 启动模板、wandb 记录。

### 1.3 竞品格局（2024–2026）

| 方法 | 优化器 | 相对 Model Swarms | 弱点（我们的切入点） |
|---|---|---|---|
| Model Swarms (ICML'25) | PSO+5 补丁 | — | 困在仿射包（Thm）、步长手拍 |
| GENOME+ (2503.01155) | GA+PSO记忆+集成 | 平均 **+10.75%** | 噪声固定 σ=0.001 盲向；推理期集成 +1.4× 成本 |
| MERGEvolve (2606.28373) | merge 初始化 + ES 噪声 | 11/12 数据集胜，整体 "competitive" | 百万维盲噪声，效率低 |
| Heterogeneous Swarms (2502.04510) | 图结构+权重 PSO | 平均 +18.5%（12 任务） | 换问题（多 LLM 系统）；NLGraph 上仍输 Model Swarms |
| Sakana EvolMerge (Nat. MI'25) | CMA-ES（2 模型层间系数）+ GA | setting 不同 | 未在专家池适配 benchmark 上验证 |

**跨论文数字不可比的铁证**：同为 gemma-2-2b 上的 Model Swarms GSM8k，GENOME 论文报 45.82，MERGEvolve 论文报 48.90（差 3 分 > 多数算法间差距）→ 同框架受控对比是空白（见 N3）。

## 2. 分析层创新（N1）：α 空间重构与二层逃逸

### 2.1 重构：这是 n 维问题

追踪现有方法的全部算术（杂交插值、速度更新、交叉），所有候选解恒为

  **x = Σᵢ αᵢ eᵢ，α ∈ Rⁿ，n = 10**

即整个搜索发生在专家张成的 **≤10 维线性子空间**。现有方法都在百万维参数空间操作物化权重；按 10 维问题设计算法带来：协方差/结构学习可行、内存 O(n)、结果天然可解释（α 分量 = 专家贡献）。

### 2.2 二层逃逸理论（本文分析贡献）

引用并扩展 MERGEvolve 的定理（Thm 1–3：凸组合困于凸包；PSO 更新困于仿射包 {Σαᵢ=1}），我们提出逃逸的分层：

| 层 | 逃逸手段 | 效率 | 现有方法的做法 |
|---|---|---|---|
| **L1：逃出仿射包**（系数和≠1） | α 空间加扰动/外插即可 | **高**（低维定向） | 无人显式利用；GENOME/MERGEvolve 用参数噪声低效地蹭 |
| **L2：逃出张成空间**（新方向） | 必须参数空间噪声 | 低（百万维盲走，σ=0.001 ≈ 原地抖动） | GENOME/MERGEvolve 唯一的逃逸手段 |

### 2.3 解释力（分析层的价值）

1. **PSO 平台期**（我们 nlgraph 0.48）：仿射包内局部最优，restart 粒子仍在包内 → 救不回
2. **GENOME 变异贡献小**（消融仅 −4.72%）：高维噪声干 L1 的活，效率天然低
3. **MERGEvolve 只是 competitive**：L2 盲走收益有限，其真正的分来自 merge 初始化（凸包内基本盘，去掉后 Flores −69%）
4. **hellaswag 的 dev-test 漂移**：dev 200 条噪声 σ≈0.035，与算法间差距同量级 → 评估协议必须抗噪（rank/复评/多保真）

## 3. 方法

### 3.1 Phase 1 基线：αCMA（仿射包感知的多保真 CMA-ES）

目的：强基线 + 验证 N1/N2 通用件。若 Phase 2 失败则升格为主线（保底）。

```
es = CMA(x0=best_single 的 one-hot 或均匀, σ0=0.3, popsize=12, 软边界[-0.5, 1.5])
初始化混合: 70% 凸组合采样 + 30% 外插点(系数和 ∈ [0.5, 1.5])   ← 仿射包感知
循环: ask(12 个 α) → 50 条粗评 → top-4 升 200 条全评 → tell(排名)
```

### 3.2 Phase 2 主算法：LP-Merge

**设计原则**：每个组件对应一个已量化的失败模式（拒绝缝合怪）。

| 组件 | 治什么 | 证据 |
|---|---|---|
| ① 稀疏选择先验 | 专家池大部分无关；CMA 各向同性不懂稀疏 | GENOME 掩码率 0.2 的间接证据；专家多样性文献 |
| ② 协同矩阵引导配对 | 好组合是"对"级别的结构，一阶方法学不到 | 领域空白；无人在合并场景学 pairwise 协同 |
| ③ 定向外插 | L1 逃逸要定向而非各向同性 | N1 二层分析 |
| ④ rank 截断 + 自适应尺度 + 记忆 | 通用骨架（选择压/步长/记忆） | GENOME 消融：选择 −14.68% 最大项 |

**伪代码**：

```
输入: 专家池 e_1..e_n (n=10), 效用 f, 预算 B
状态: 种群 P (M=12 个 α ∈ Rⁿ), 个体最优 {p_i}, 全局最优 g,
      协同矩阵 S ∈ R^{n×n}, 步长 σ, 停滞计数 t

初始化: 凸组合采样 70% + 外插点 30%（系数和 ≠ 1）→ 全量评测 → 记录 (α, f)

while 预算未耗尽:
    ── 评测（多保真）──
    新个体先在 50 条子集粗评 → 前 1/3 升 200 条全评 → 复评 top-2（防 dev 噪声，§2.3-4）

    ── 选择与记忆 ──
    rank 截断保留 top-M/2；更新 p_i, g
    更新协同矩阵: S ← (1-η)S + η·[高分个体中专家共现的统计]
    步长: g 改善 → σ×1.1；t 停滞 → σ×0.85；t≥T_max → 重启（回 p_i 邻域, σ 重置）

    ── 生成新一代 ──
    a) 记忆重组+定向外插 (40%): α' = g + β(g − parent), β~U(0, 0.3)   ← L1 定向逃逸
    b) 协同探索 (30%): 从 S 选高分但历史低访问的专家对 (i,j)，
       生成以 e_i,e_j 为主的稀疏 α                                      ← ②
    c) 稀疏重置 (20%): 把贡献最低 ⌈n/3⌉ 个系数清零 + 小噪声重探索        ← ①
    d) 随机外插 (10%): 系数和 ≠ 1 的均匀采样（保底）                     ← L1 随机逃逸

输出: g（及物化 LoRA）
```

（各比例 40/30/20/10 为初始值，随消融调整。）

### 3.3 机制对比

| 机制 | PSO | GENOME+ | CMA-ES | **LP-Merge** |
|---|---|---|---|---|
| 选择压 | ✗（弱） | ✓ 截断+轮盘 | ✓ rank 加权 | ✓ rank 截断 |
| 个体记忆 | ✓ p_i | ✓ succession | ✓（分布均值） | ✓ p_i/g |
| 步长自适应 | ✗（λ×0.95 手拍） | ✗（固定 σ） | ✓ CSA | ✓（进展驱动） |
| 方向学习 | ✗ | ✗ | ✓ 协方差 | ✓（协同矩阵，pairwise 级） |
| 稀疏先验 | ✗ | △（元素掩码） | ✗ | ✓（专家级） |
| L1 定向逃逸 | ✗（困仿射包） | ✗（盲噪声） | △（间接） | ✓（外插原生） |
| 多保真评测 | ✗（Drop-K/N 粗糙） | ✗ | ✗ | ✓ |

## 5. 实验计划

### 5.1 打靶实验（第一个）

nlgraph 上 LP-Merge / αCMA vs 我们复现的 PSO 基线 **0.48**。突破 → 论文 Figure 1。

### 5.2 主实验

- 数据集：nlgraph、hellaswag、gsm8k（GENOME 赢最多的任务，检验能否同样赢）
- 预算对齐：所有方法相同评估次数（如 20×50 = 1000 次物化评测）
- 种子：每配置 ≥3
- 报告：dev 曲线 + **test 终值**（吸取 hellaswag dev-test 漂移教训）+ 评估次数

### 5.3 消融阶梯（每档算一次分）

```
V0  纯 rank 选择+记忆骨架（≈退化基线）
V1  + 固定 σ 各向同性噪声            ← 逃逸本身值多少分（对照 GENOME）
V2  + 自适应尺度                     ← 尺度自适应值多少分
V3  + 定向外插（L1 结构化逃逸）       ← N1 主张 2 的直接验证
V4  + 协同矩阵引导                   ← 领域特异件值多少分
V5  + 稀疏先验
V6  + 多保真（同预算多跑 2× 迭代）    ← 样本效率值多少分
```

### 5.4 N1 验证（一次实验喂全链）

200 个随机 α × 2–3 数据集的地形扫描：① 画地形图（论文 Figure 2 / 分析章）② 回答 0.48 是仿射包限制还是 span 限制 ③ 为协同矩阵/多保真提供先验数据。

## 6. 实现方案

```
merge_swarm/
├── search.py                 # 原版 PSO（不动，加 --algorithm 开关）
├── alpha_space.py            # 新增：α 物化层（Σαᵢeᵢ → 临时 LoRA，复用 lora_merge）
├── search_acma.py            # 新增：αCMA（pycma 或手搓 ~200 行）
├── search_lp.py              # 新增：LP-Merge
└── evaluate.py               # 完全复用（含多保真入口：subset_size 参数）
```

- α 物化层缓存 10 个专家 delta，每次合并只需 n 次加权加法（秒级）
- GPU 分配：M=12 个候选 ÷ 4 卡 = 每卡 3 个
- wandb 同项目记录，run 名带算法标识（对比方便）

## 7. 风险与保底

| 风险 | 应对 |
|---|---|
| LP 各特化组件不奏效 | αCMA 升主线（保底剧本），LP 组件结果进消融分析 |
| 多保真粗评噪声误导选择 | top-2 复评 + 粗筛只用于淘汰尾部（不用于排序精英） |
| 0.48 是 span 天花板 | §5.4 随机扫描先行诊断；若是 → 转向"天花板分析"本身也是发现 |
| GENOME+ 复现成本 | 权重开源单卡可跑，可后置；先以 PSO+αCMA 为主对照 |
