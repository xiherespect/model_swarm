# LP-Merge 对比原版 Model Swarms：逐步改了什么

**白话版对照说明 v0.1** · 2026-09-05 · 配套详细设计见 [lp_algorithm_design.md](./lp_algorithm_design.md)

---

## 0. 一句话

原 Model Swarms：**一条平均公式**推着 20 个粒子走，永远走不出 10 个专家围成的圈；
LP-Merge：**四种生成器 + 淘汰制 + 地形图 + 分级评估**，专门针对它的六个环节逐个换掉。

---

## 1. 逐步对照表

| 环节 | 原 Model Swarms（search.py 现状） | LP-Merge | 改的理由 |
|---|---|---|---|
| **① 表示模型的方式** | 存物化 LoRA 权重（每粒子 x/v/p 三份 × 37MB） | 只存 10 个合并系数 α（权重 = Σαᵢeᵢ，评估时才物化） | 所有权重本来就是 10 专家的线性组合；存系数省内存、天然可解释（αᵢ = 专家 i 的贡献），并使 ②外插、⑥地形图 成为可能 |
| **② 产生新候选** | 一条公式：新位置 = 惯性速度、个人最优、全局最优、全局最差的加权平均 | 四种生成器按比例混合（§2） | 平均公式系数和恒等于 1 → **数学上被锁死在 10 专家张成的仿射包内**（MERGEvolve Thm 3）；nlgraph 0.48 平台期即此表现，restart 救不回 |
| **③ 淘汰机制** | 无。20 个粒子永远在，坏粒子只 restart 回个人最优，位置照占 | rank 截断：后一半直接扔 | GENOME 消融：去掉选择压平均掉 14.68%，是最大单项 |
| **④ 步长** | λ×0.95 每轮固定衰减（手拍） | 看疗效：g 在涨→放大；停滞→收缩 | 固定衰减在顺利时太保守、停滞时收缩太慢（CMA-ES CSA 的思想） |
| **⑤ 评估** | 每个候选全量 200 条 dev | 50 条粗筛 → 幸存者升 200 条 → 冠军复评 | 同预算多近一倍迭代；压制 dev 选择噪声（hellaswag dev↑test↓ 的教训：200 条噪声 σ≈0.034 与提升量同量级） |
| **⑥ 记忆** | 只记点：p_i（个人最优）+ g（全局最优） | 点照记，另加地形图：全部历史 (α, f) 拟成 55 参数二次模型 f(α)≈Σβᵢαᵢ+Σβᵢⱼαᵢαⱼ | PSO 的记忆知道"哪里好过"，不知道"哪里为什么好"；二次模型还免费提供 βᵢⱼ 协同系数和 βᵢ 稀疏名单 |

## 2. ②的四种生成器（算法核心）

1. **记忆重组 + 定向外插**（主力 ~40%）：`α' = g + β(g − parent)`，β~U(0, 0.3)。
   关键：最后一步往 g 方向**多走一段**，系数和 ≠ 1 → 走出仿射包。原公式做不到，是结构性限制而非调参问题。
2. **协同生成**（~30%）：二次模型的交互项 βᵢⱼ 指出"专家 i、j 搭伙分数高且该组合历史少试"→ 专门生成这种 α。原公式只会"大家都靠向 g"，表达不出"A 与 B 有化学反应"。
3. **稀疏重置**（~20%）：βᵢ 主效应 + 交互质量 ≈ 0 的专家系数清零重探索。原方法不会主动丢弃无用专家。
4. **随机外插**（~10%）：系数和 ≠ 1 的均匀采样，保底多样性。

（比例为初始值，随消融调整。）

## 3. 一轮具体迭代对比（以 nlgraph 为例）

**原版**：20 粒子全部按同一条公式挪一步 → 全部全量评 200 条 dev（~6 分钟）→ 更新最优 → 坏粒子照常占位 → λ×0.95。

**LP-Merge**：12 候选 = 5 精英外插 + 3 协同生成 + 2 稀疏重置 + 2 随机 → 11 个先 50 条粗评（~1 分钟）→ 前 4 名升 200 条精评 → rank 截断扔后一半 → 新数据喂二次模型（lstsq，毫秒级）→ 按停滞/改善调整步长。

## 4. 改动分量标注（诚实版）

| 类别 | 改动 | 说明 |
|---|---|---|
| 抄作业（已证明有效，不新但必须） | ③ 选择压（GENOME 证明）；④ 自适应步长（CMA-ES 思想） | 站在别人的消融/理论上 |
| 地基（本身不算创新） | ① α 表示 | 让外插、地形图、协同成为可能；另可从任意已存权重反解 α（span 检验） |
| **真正押注的三张牌** | ② 外插（逃出仿射包，治平台期）；② 协同生成（领域特有结构，治盲目）；⑤ 多保真（同预算 ×2 迭代，治噪声） | 论文的成败在这三处 |

## 5. 两个自然疑问与防线

**Q1：外插出圈后模型会不会崩（权重坏了、能力崩塌）？**
防线：a) 外插步长 β 有界（≤0.3）且随评估结果自适应回缩；b) 出圈候选同样要过 50 条粗筛，崩了就地淘汰，不进种群；c) g 永远保存圈内验证过的最优，出圈只在"试验田"里发生，输了不掉血。

**Q2：二次模型不准怎么办（地形不是二次的）？**
防线：a) 代理只用来"提名"协同/稀疏候选（30% 配额），不驱动主循环，错了损失有限；b) 拟合后监控 R²，R² 低就自动降低协同生成比例、提高外插+随机占比（算法对代理质量有退化容忍）；c) 用随机 α 扫描的无偏数据交叉校验 on-policy 拟合结果。
